# NeuralOps MCP — V0.1.4 Nexus Gate

> NeuralOps asal mein NeuralOps Nexus ke liye bana hai. Nexus woh jagah hai jahan log, personas aur agents saath kaam karte hain. NeuralOps us ke neeche rulebook aur record hai: persona ka koi bhi tool call asli system (Odoo, DB, email, payments) tak pahunchne se pehle yahan check hota hai. V0.1.4 mein woh 4 cheezein aayi hain jo Nexus ko is ke liye chahiye.

---

## 20.1 Kya naya hai

| # | Cheez | Kyun |
|---|-------|------|
| 1 | **`perform` act** (26th act) | Tool call chalne se pehle poocha jata hai: `allowed` mile to chalao, warna approval ka intezaar karo. Har call ledger mein darj hota hai |
| 2 | **Streamable-HTTP MCP** (`POST /mcp`) | Nexus MCP servers ko URL se jodta hai (streamable-http default). Har persona apne bearer token se aata hai aur apni hi identity se act karta hai |
| 3 | **Python guard** (`integrations/nexus/neuralops_guard.py`) | `nexus-ai` (pydantic-ai) ke andar `process_tool_call` hook. Stdlib only, koi nayi dependency nahi |
| 4 | **Kill switch** | `POST /api/admin/freeze` se saare agents aur personas ek saath ruk jate hain: acts, gates, guard, Claude/Codex/Gemini hooks aur pre-commit, sab block. `unfreeze` se wapas chalu |
| 5 | **LICENSE** | Apache-2.0. Yeh AGPL-3.0 (Nexus) ke saath compatible hai |

## 20.2 `perform` ke rules

```
perform { action: "odoo.write", scope: "production", target: "odoo/create_invoice", detail: "{partner: ACME, amount: 5000}" }
```

| Halat | Nateeja |
|-------|---------|
| Agent ke paas `odoo.write/production` ki direct authority hai | `allowed: true` (via authority) |
| Is action pe koi policy nahi | `allowed: true` (via ungoverned), phir bhi ledger mein darj |
| Policy hai aur approved (unused) approval maujood hai | `allowed: true`; approval **consume** ho jati hai (single-use) |
| Policy hai aur approval pending hai | `allowed: false`, wahi approval id milti hai (nayi nahi banti) |
| Policy hai aur koi approval nahi | nayi approval banti hai aur `detail` approver ko dikhta hai; `allowed: false` |
| Workspace frozen | act reject (403 "FROZEN") |

- Requester apni approval kabhi approve nahi kar sakta. Jis ke paas `deny/<scope>` authority ho, woh veto kar sakta hai.
- `*`/`*` policy lagao to har action pe approval chahiye hogi (default-deny).
- `detail` requester agent ka likha hua text hai, is liye approver ke inbox mein woh flagged data ki tarah dikhta hai, instruction ki tarah nahi.

## 20.3 Kill switch

```bash
curl -X POST $CORE/api/admin/freeze   -H "Authorization: Bearer $ADMIN" -d '{"reason":"Layla ne ghalat ledger mein likha"}'
curl -X POST $CORE/api/admin/unfreeze -H "Authorization: Bearer $ADMIN"
```

- Freeze admin record ki shakal mein journal hota hai, is liye restart ke baad bhi frozen hi rehta hai, aur replay match karta hai.
- Dashboard pe laal "Workspace frozen" banner aata hai. `/api/health`, `/api/freeze`, `/api/inbox` aur `/api/reservations/check` sab `frozen` batate hain.

## 20.4 Nexus mein setup

Poori guide: `mini-services/neuralops-mcp/integrations/nexus/README.md`. Mukhtasar:

1. Core ko secure mode mein `NEURALOPS_HOST=0.0.0.0` pe chalao. `nexus-ai` container ke andar se `localhost` kaam nahi karta, host ka asli IP do.
2. Har insaan (approver) aur har persona ko `POST /api/agents` se register karo. Har ek ka apna token hota hai.
3. Policies lagao, jaise `odoo.write/production → agent.noaman`.
4. `nexus-ai` mein MCP toolsets ko `process_tool_call=guard.process_tool_call` do.
5. (Optional) NeuralOps ko Nexus mein MCP server ki tarah register karo: `http://<host-ip>:3031/mcp`, streamable-http, header mein `Authorization: Bearer <persona token>`. Agar header nahi bhej sakte to `NEURALOPS_MCP_URL_TOKENS=1` karo aur URL `/mcp/<token>` use karo.

## 20.6 Limits (honest)

- Abhi tak kisi asli Nexus deployment mein nahi chalaya gaya. Integration points Nexus ke README se liye gaye hain.
- Nexus ke users (Supabase) khud-ba-khud map nahi hote; har ek ko ek dafa register karna padta hai.
- Approval single-use hai: ek hi governed action baar baar karna ho to har baar approval chahiye. Batch ya time-boxed approvals agla qadam ho sakta hai.
- Identity ids `agent.<name>` format mein hain, insaanon ke liye bhi.
